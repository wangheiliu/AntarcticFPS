# AntarcticFPS

> AntarcticFPS is my first game and it is a low-poly fps game where penguins fight each other to reach a goal. The goal maybe to get points, be the last one standing, and more!

# Third Party assets used

This project uses assets from the Unity Asset Store

* **[Low-Poly Office Set #1](https://assetstore.unity.com/packages/3d/props/low-poly-office-set-1-140-models-vnb-327126) ** by VNB Productions - Used as a way to test player movement

# Current Features
* Basic player movement
* Sprinting/crouching mechanic
* Basic sliding mechanoc
